# Upalit Backend — Auth + Admin Panel API

A working, tested backend covering account login and an admin panel for managing investors and property/token listings.

## Quick Start

```bash
# Clone and install
npm install

# Create environment file
cp .env.example .env
# Edit .env with your secrets

# Seed the database
npm run seed

# Start the server
npm start
# Or for development with auto-reload:
npm run dev
